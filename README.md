# The Dog Ate My Homework: Funniest Excuse

A one-line excuse, in the dog's own voice, for the [make.fun bounty](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c): caught red-pawed eating the homework, the dog takes the assignment's own instruction literally — "show your work" — and files it straight into its stomach, where it is being graded as we speak. A dog who believes it has done nothing wrong.

Run `python3 main.py` and it writes the excuse to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`): a single line, under 200 characters, no trailing newline.
